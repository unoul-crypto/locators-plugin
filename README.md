# Locators

Плагин для Bukkit-совместимых серверов, добавляющий настраиваемые предметы-локаторы. При клике ПКМ
локатор показывает только использовавшему его игроку подходящие цели, примерное расстояние и
относительные углы до них.

## Требования и сборка

- Minecraft 1.16.5 или новее
- Bukkit-совместимое ядро: Spigot, Paper, Purpur, Mohist, Youer и аналогичные
- Java, требуемая сервером; байткод плагина совместим с Java 8+
- Maven 3.9+
- LuckPerms 5.x — необязательная зависимость

```powershell
mvn clean package
```

Готовый файл: `target/Locators-1.3.0.jar`. Поместите его в `plugins` и перезапустите сервер. При первом
запуске появится `plugins/Locators/locators.json`.

Плагин компилируется против Spigot API 1.16.5, использует `api-version: 1.16` и не обращается к
CraftBukkit/NMS. Это позволяет одному JAR работать на большинстве актуальных Bukkit-совместимых ядер.

## Формат locators.json

```json
{
  "locators": [
    {
      "id": "basic",
      "item": "minecraft:compass",
      "showDistance": true,
      "distanceError": 10.0,
      "showYaw": true,
      "yawError": 5.0,
      "showPitch": false,
      "pitchError": 0.0,
      "maxDistance": 500.0,
      "targetMode": "scoreboard_tag",
      "target": "enemy",
      "cooldownSeconds": 30.0,
      "cooldownMode": 1,
      "usePermission": "locators.use.basic",
      "givePermission": "locators.give.basic"
    }
  ]
}
```

- `id` — уникальный ID из строчных латинских букв, цифр, `_`, `.` и `-`.
- `item` — ID предмета Minecraft.
- `showDistance`, `showYaw`, `showPitch` — какие данные выводить.
- `distanceError`, `yawError`, `pitchError` — случайная погрешность `±` соответствующего значения.
- `maxDistance` — максимальная дистанция до цели в блоках.
- `targetMode` — способ фильтрации: `scoreboard_tag` или `luckperms_group`.
- `target` — имя scoreboard-тега/группы LuckPerms либо `all` для всех игроков.
- `cooldownSeconds` — cooldown локатора, можно использовать дробное число.
- `cooldownMode` — `1` для общей пары «игрок + тип локатора», `2` для каждого физического предмета.
- `usePermission` — право на использование; пустая строка разрешает использование всем.
- `givePermission` — право на выдачу; пустая строка разрешает выдачу всем.

Старый параметр `targetTeam` поддерживается: если `target` отсутствует, его значение используется как
scoreboard-тег, а отсутствующий `targetMode` считается `scoreboard_tag`. Отсутствующий `cooldownMode`
считается режимом `1`.

### Фильтрация целей

В режиме `scoreboard_tag` проверяются теги, назначаемые ванильной командой:

```text
/tag <игрок> add enemy
/tag <игрок> remove enemy
```

Игрок может иметь одновременно несколько таких тегов.

В режиме `luckperms_group` учитываются первичная, непосредственные и унаследованные группы LuckPerms в
активном контексте игрока. LuckPerms подключается как необязательная зависимость. Если он не установлен,
не запущен или его API недоступен, плагин автоматически ищет у игрока scoreboard-тег с именем из
`target`. Значение `all` не требует ни тега, ни группы.

Учитываются только другие онлайн-игроки в том же мире.

### Кликабельные углы

Yaw показывается как поворот вправо/влево от текущего взгляда, pitch — вниз/вверх. Значения подчёркнуты
и кликабельны: нажатие поворачивает камеру, не меняя позицию игрока. Yaw меняет только горизонтальный
поворот, pitch — только вертикальный. Ссылку можно использовать многократно в течение 120 секунд; она
привязана к получившему результат игроку.

### Cooldown

Активные cooldown хранятся в `plugins/Locators/cooldowns.json` как абсолютное время окончания. Файл
загружается при запуске и атомарно обновляется при штатной остановке или перезагрузке плагина. Истёкшие
записи удаляются. В режиме `2` каждый локатор получает скрытый UUID и выдаётся отдельным предметом.

## Команды

- `/locators give <ник> <id> <количество>` — выдать локатор; требует `givePermission` выбранного типа.
- `/locators reload` — перечитать JSON; требует `locators.reload` (по умолчанию OP).
- `/locator resetTypeCooldown <тип|*> <UUID|ник|*>` — сбросить cooldown режима `1`; требует
  `locators.resetcooldown` (по умолчанию OP).

Если инвентарь получателя заполнен, лишние предметы выпадут рядом с ним. Количество за одну команду
ограничено диапазоном от 1 до 6400.
